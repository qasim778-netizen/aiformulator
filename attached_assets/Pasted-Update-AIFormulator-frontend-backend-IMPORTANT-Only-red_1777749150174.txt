BACKUP / FALLBACK LOGIC

Add strong backup logic:

1. Database cache fallback:
If exact formula_key not found, try similar match:
- Same category
- Same productType
- Same baseType
- Same performanceLevel
- Ignore budget/volume first
- If found, return saved formula and adjust displayed productName

2. OpenAI failure fallback:
If OpenAI API fails, times out, or returns invalid JSON:
- Retry once with same structured input
- If still fails, save failure in formula_generation_failures
- Show friendly message:
  “Formula generation is temporarily unavailable. Please try again in a few minutes.”
- Do not charge user credits twice

3. JSON validation fallback:
If OpenAI response is not valid JSON:
- Attempt to repair/parse JSON
- If repair fails, retry once
- If still invalid, store failure log

4. Required ingredient/formula validation:
Before saving output:
- Ensure formulation percentages total 100%
- Ensure formulationTable exists
- Ensure manufacturingProcess exists
- Ensure safetyNotes exists
- If total is not 100%, ask OpenAI once to correct percentages
- Save only corrected version

5. Existing formula backup:
If OpenAI fails but a similar formula exists:
- Return similar saved formula
- Add internal flag:
  source = "cache_fallback"
- Do not show this technical detail to user

6. Admin log:
Log every API failure, invalid JSON, and fallback use for admin review.
